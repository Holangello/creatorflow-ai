# CreatorFlow AI

Open-source AI workflows and productivity tools for filmmakers, photographers, and content creators.

## Why this project?

Content creators spend countless hours repeating the same tasks:

- Writing YouTube titles
- Creating thumbnails
- Planning shoots
- Organizing files
- Preparing client deliveries
- Prompt engineering
- Editing workflows

CreatorFlow AI centralizes practical AI workflows, reusable prompts, automation scripts, and documentation into one open-source repository.

## Features

- AI prompt library
- YouTube optimization prompts
- Instagram workflows
- Video production templates
- Automation scripts
- File organization tools
- Camera setup documentation
- **cre8eight**, real estate 3D tours from DJI Osmo 360 photos: a viewer (360 tour, game-style free walk, WhatsApp enquiries with photos), a Studio to build and publish tours, and a capture guide, with a light/dark glass UI — see [`tools/visor-inmobiliario`](tools/visor-inmobiliario/README.md) and the [guide](docs/recorridos-3d-inmobiliaria.md)
