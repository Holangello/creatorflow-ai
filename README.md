# CreatorFlow AI

Open-source AI workflows and productivity tools for filmmakers, photographers, and content creators.

## Why this project?

Content creators spend countless hours repeating the same tasks:

- Writing YouTube titles
- Creating thumbnails
- Planning shoots
- Organizing files
- Preparing client deliveries
- Prompt engineering
- Editing workflows

CreatorFlow AI centralizes practical AI workflows, reusable prompts, automation scripts, and documentation into one open-source repository.

## Features

- AI prompt library
- YouTube optimization prompts
- Instagram workflows
- Video production templates
- Automation scripts
- File organization tools
- Camera setup documentation
- B2B marketing and sales rules

## Roadmap

- Prompt library
- Python utilities
- DaVinci Resolve helpers
- Premiere Pro tools
- Lightroom workflows
- Camera guides
- AI automation

## Marketing and sales rules

Marketing, sales and commercial content for **angellobenavides.com** and
**agenciamakers.com (Makers)** must follow
[`docs/b2b-marketing-sales-rules.md`](docs/b2b-marketing-sales-rules.md).
The rule is B2B first (80/20): B2C content only exists when it feeds the B2B
funnel.
