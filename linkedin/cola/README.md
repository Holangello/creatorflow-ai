# Cola de piezas

Vacía a propósito.

Fase actual del sistema: **estructura y planning**. Todavía no se redactan piezas.
El calendario (`../calendario.md`) define título y descripción de cada publicación; la
redacción se hará a demanda, día a día, cuando Angello la pida:

```
Maverick, escribe la pieza del 15 de septiembre.
Maverick, redacta la pieza de actualidad de hoy sobre [noticia].
```

Cuando una pieza se escriba, se guarda aquí como `AAAA-MM-DD-slug.md` y su fila del
calendario pasa de `planificada` a `creada`.
