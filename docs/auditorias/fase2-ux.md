# Auditoría fase 2 · UX del Estudio, los paneles y el Asistente

## Problemas principales

| # | Problema | Responsable |
|---|---|---|
| P1 | QR imposible de escanear: el SVG heredaba el trazo de los iconos | **Corregido** |
| P2 | La vista previa del Estudio muestra datos de la demo | paneles |
| P3 | Estudio inutilizable en iPad vertical (≤860 px) | Estudio |
| P4 | Avisos técnicos repetidos en Orientar | Estudio |
| P5 | Paso Plano saturado a 1024 px | Estudio |
| P6 | Revisar dice "Todo correcto" con 4 avisos | Estudio |
| P7 | Jerga técnica (yaw, GPano, splat, webhook, CORS…) | Estudio |
| P8 | Exportar no indica qué hacer primero | Estudio |
| P9 | Los errores del formulario no se borran al corregirlos | paneles |
| P10 | No se entiende cómo enviar fotos por WhatsApp | paneles |
| P11 | La barra de captura se sale en móvil horizontal | paneles |
| P12 | "Hacer foto" queda escondido; el botón de contacto es distinto según la pantalla | paneles |
| P13 | El formulario de Datos es muy denso | Estudio |
| P14 | El Asistente y el Estudio no parecen un mismo producto | diseño / Estudio |
| P15 | Contraste, tamaño de los objetivos táctiles y atajos de una tecla | Estudio / diseño |

## Propuestas

- Flujo principal en 5 pasos, con el resto en "Avanzado".
- Modo **Rápido** de unos 5 minutos.
- Botón **Continuar** en cada paso.
- 20 textos reescritos.
